# Neon Breakout · Day & Night Edition

直接用瀏覽器開啟 `neon_breakout_arcade.html`。不需安裝套件，也不依賴 CDN 或外部圖片。

## 檔案

- `neon_breakout_arcade.html`：頁面、遊戲 HUD 與對話框。
- `styles.css`：日夜主題、響應式介面與動畫。
- `js/levels.js`：8 個關卡主題、一般 18 × 10 / 無盡 18 × 28 隨機磚陣生成器、難度、道具與成就資料。
- `js/game.js`：Canvas 繪圖、固定時間步進物理、碰撞與關卡機制。
- `js/app.js`：導覽、選關、設定、存檔、音效與輸入操作。
- `backup/neon_breakout_arcade.original.html`：修改前的原版備份。

## 操作

| 操作 | 鍵盤 / 指標 |
| --- | --- |
| 移動擋板 | ← / →、A / D、滑鼠、觸控拖曳、手機左右按鈕 |
| 發球 | 點擊球場、空白鍵、手機發球按鈕 |
| 能量脈衝 | 能量 100% 後按空白鍵或脈衝按鈕 |
| 暫停 / 繼續 | P / Esc、右上角暫停按鈕 |
| 日夜切換 | 頁首太陽 / 月亮；設定可選每 45 秒自動切換 |

一般關卡的磚陣基礎尺寸是高 18 列 × 寬 10 欄，無盡模式則是高 18 列 × 寬 28 欄（504 個格位）。無盡模式自動縮小磚塊寬度，讓 28 欄完整放入球場。每次開始、重新挑戰或進入新波次，都會產生新的隨機磚陣；保留各關的特色輪廓與障礙機制，保證每列至少有三塊可破壞磚、每欄至少兩塊。選關預覽會顯示接下來那次挑戰的實際配置。

無盡模式清空一波後，3 秒自動接續下一波，也可按按鈕立即繼續。總分、生命與能量跨波保留；每完成 3 波補 1 點生命，最多 6 點。球速逐波增加並設有上限；後續波次加入裝甲、爆破磚、移動磚陣與障礙。生命歸零結算，各難度分別儲存最高分與最高到達波次。主動離開也會保存無盡紀錄，但不儲存尚未完成的場內盤面。

一般關卡每關最多三顆星：完成關卡、無任何球落下、目標時間內通關。
灰色鋼磚無法破壞，不計入通關目標；十字磚會連鎖爆破，白點磚帶有裝甲。
各難度分開儲存最佳分數、星級與最快通關時間，成就跨難度累積。
自動晝夜依遊戲進行時間計算，暫停不會推進時間。

進度存於瀏覽器的 localStorage；同一個檔案改用不同瀏覽器、不同網址或清除瀏覽資料，紀錄可能不同。儲存被禁用時可繼續遊玩，介面會顯示暫存提示。會保留原版的最高分紀錄。

休閒／標準／挑戰有不同球速、擋板大小、目標時間與分數倍率。切換頁籤或視窗、開啟設定或指南時會暫停。可減少動態效果、調整音量、關閉音效。

新增關卡可在 `js/levels.js` 的 `Neon.levels` 加入資料；目前頁面進度數字以 8 關 / 24 星設計，如擴充關卡也需同步更新該顯示。`map` 是隨機生成器的造型參考，不是固定關卡。字元：`0` 空格、`1` 普通磚、`2` / `3` 裝甲磚、`X` 爆破磚、`S` 鋼磚。造型參考每列 10 格；生成器會將輪廓展開為一般 18 × 10 或無盡 18 × 28，並隨機調整空格、磚型與裝甲。

開發驗證：`node --test tests/engine.test.cjs`。可選本機預覽：`node tools/preview.cjs`，開啟 `http://127.0.0.1:4173`。
